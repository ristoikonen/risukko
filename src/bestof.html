Binary Layout Structure

[ Magic Header: 2B (0x52, 0x49 for 'RI') ]
[ Version     : 1B (0x01) ]
[ Width       : 2B UInt16 ]
[ Height      : 2B UInt16 ]
[ Padding     : 1B UInt8  ]
[ Style Flags : 2B UInt16 ]
[ Seed / Hash : 4B UInt32 ]
[ Payload Bytes (Variable)]
[ RS Parity   : 16B GF(2^8) ]
